# Matrícula pendente e ativação explícita

A matrícula pode ser registrada como pendente, sem participação acadêmica, e ativada explicitamente pela secretaria com permissão específica quando os requisitos definidos pela instituição forem atendidos. Em vez de exigir que tudo esteja pronto para registrar o vínculo, essa separação permite acompanhar pendências sem liberar a participação acadêmica. Exceções aos requisitos exigem autorização própria, motivo e auditoria; o alcance da autoridade administrativa para essas exceções ainda será detalhado.

Os requisitos são configurados por oferta, distinguindo os obrigatórios daqueles que admitem exceção autorizada. A ativação de matrícula com ciclo individual define uma data explícita de início, registrada com a versão das regras aplicável; o primeiro acesso do aluno pode ocorrer depois.

O início retroativo pode ser registrado pela secretaria com permissão específica e justificativa, usando a versão de regra vigente na data informada. Se essa versão não estiver cadastrada, a operação fica pendente de regularização.
