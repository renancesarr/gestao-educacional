# Regras acadêmicas versionadas por ciclo

Cada tenant define regras acadêmicas para suas ofertas, com variações por etapa e modalidade na Educação Básica e regras próprias para a graduação, e publica versões com vigência. Um ciclo acadêmico usa a versão com que começou: nas turmas regulares o período pode ser comum, enquanto no EAD cada matrícula pode ter ciclo individual e acelerado. Nesse caso, a conclusão é registrada para cada matrícula após cumprir atividades, avaliações e demais requisitos da oferta, sem encerrar os ciclos dos outros alunos. Essa escolha preserva os critérios aplicados a cada aluno; transferir um ciclo iniciado para outra versão é exceção explícita, motivada e auditada.

No retorno do trancamento, o cadastro atualizado é utilizado, mas o ciclo mantém sua versão original das regras. A troca de versão depende de alteração explícita pelo ADMIN (`SUPER_ADMIN`), com motivo e auditoria; atualizar o cadastro não troca a versão acadêmica.

A decisão explícita do ADMIN é final e não exige prévia de recálculo com confirmação adicional nem aprovação de outro ator. A auditoria registra a alteração, sem constituir uma etapa de autorização. Esta definição de autoridade não determina, por si só, o alcance de eventual recálculo sobre resultados anteriores.
